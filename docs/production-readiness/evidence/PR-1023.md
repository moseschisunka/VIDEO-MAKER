# PR-1023 — Fail closed on malformed asset-review controls

Status: `IMPLEMENTED` locally; supported CI verification remains required.

## Finding

Visual asset and contact-sheet gates converted policy flags with Python
truthiness. A value such as `sample_required=0` could disable the sample-first
gate, while malformed `batch`, `provenance_required`, or contact-sheet
`required_approval` values could make an asset request or review manifest
disagree with its boolean schema. This affected the stock-image, AI-image,
AI-video, diagram, and mixed-media paths.

## Remediation

- Validate `AssetRequest.provenance_required` and `sample_required` as actual
  booleans, including when requests arrive from mappings.
- Validate contact-sheet `required_approval` before building its manifest and
  pass the raw builder input rather than coercing it in the tool wrapper.
- Validate image/video selector `sample_required` and `batch` controls before
  constructing a generation plan or invoking a provider.
- Preserve structured no-spend failures for malformed controls and add
  regression coverage for string, integer, and null values.
