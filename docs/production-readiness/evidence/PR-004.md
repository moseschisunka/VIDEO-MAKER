# PR-004 — Golden scenarios and expected contracts evidence

**Date:** 2026-09-02
**Task status:** `VERIFIED`
**Owner:** OpenMontage execution agent
**Depends on:** `PR-001` and approved `PR-002` Option A
**Scope:** deterministic evaluation descriptors; no provider calls or paid generation

## Implemented

- Added the strict JSON Schema at
  `schemas/evals/golden_scenario.schema.json`.
- Added the eight required versioned golden scenarios under
  `tests/eval/golden_scenarios/`:
  `social_short_15s`, `grounded_explainer_30s`, `stock_documentary_60s`,
  `talking_head_basic`, `screen_demo_30s`, `mixed_media_45s`,
  `hyperframes_kinetic_typography_20s`, and `lesson_5m`.
- Each scenario declares its intended pipeline, input/source mode, profile, target
  duration and tolerance, voice intent, visual strategy, runtime candidates, expected
  approvals, expected artifact fields, and prohibited downgrade behavior.
- Added a fixture-contract README under `tests/fixtures/production_readiness/` for future
  deterministic media bytes and artifact snapshots. No credentials, generated media, or
  developer-specific absolute paths are stored.
- Corrected the existing Phase 1 golden test to load its fixture from the actual
  `tests/eval/golden_scenarios/` path instead of silently skipping it.
- Added release-blocking contract tests in
  `tests/contracts/test_phase0_golden_scenarios.py`.

## Required scenario coverage

| Required scenario | Fixture | Pipeline |

The avatar path remains represented in the pipeline classification and is intentionally
not treated as certified by the talking-head fixture; its provider/runtime gates remain
experimental until the corresponding phases pass.

## Verification

Command:

```text
python -m pytest tests/contracts/test_phase0_golden_scenarios.py tests/contracts/test_phase1_golden.py -q
```

Result: **10 passed in 0.33 seconds**.

The tests prove that:

- exactly eight required scenario files exist;
- every file validates against the strict schema;
- fixture names and intended pipeline names agree;
- duration values are consistent between top-level and input contracts;
- every scenario has explicit runtime candidates, approval gates, and prohibited
  downgrade rules; and
- no fixture contains an API-key/secret marker or developer-specific absolute path.

No source pipeline behavior was certified by this task. `PR-005` must record the runtime
and reliability baseline against this fixture set, and `PR-0G` still requires the complete
Phase 0 evidence set. Production remains ineligible until every roadmap gate through
`PR-11G` passes.
