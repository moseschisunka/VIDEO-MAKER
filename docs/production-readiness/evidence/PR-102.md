**Depends on:** `PR-101` (`VERIFIED`)
**Next task:** `PR-103` — pre-mutation request validation

## Implemented contract

`lib.pipeline_loader.list_pipeline_catalog()` is now the single release-aware
catalog builder. It loads manifests through `load_pipeline_readonly`, records
schema validity and stage order, applies the approved release-scope metadata,
and sorts launch candidates before held lanes. `include_hidden=True` is reserved
for audit/diagnostic views; ordinary callers receive only user-visible entries.

Backlot `/api/pipelines` delegates directly to this function, so the wizard
receives the same records as the loader/CLI surface. Each record carries its
manifest maturity, supported runtime/profile/capability/artifact metadata,
release lane, availability, creation permission, `production_ready: false`,
and mandatory `production_gate: PR-11G`. `framework-smoke` is retained only in
the hidden audit catalog.
