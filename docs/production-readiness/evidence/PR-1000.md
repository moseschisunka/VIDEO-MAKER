# PR-1000 — One dependency truth

- Status: **VERIFIED**
- Gate date: 2026-09-02
- Gate owner: OpenMontage execution agent
- Scope: Python runtime/development/GPU dependency declarations, legacy setuptools compatibility, and the Remotion package lock.

## Implementation

- `pyproject.toml` is the authoritative Python metadata and dependency declaration.
- `setup.py` is a compatibility shim that delegates to `pyproject.toml`; it contains no second `install_requires` or package-discovery list.
- `requirements.txt`, `requirements-dev.txt`, and `requirements-gpu.txt` are checkout-friendly wrappers for the project, `dev`, and `gpu` extras respectively.
- `filelock` is explicitly a runtime dependency because approval, checkpoint, run, and output-promotion state use locked writes.
- The GPU extra now contains the complete GPU stack previously split between `requirements-gpu.txt` and the Makefile (`torch`, `torchaudio`, `torchvision`, `diffusers`, `transformers`, and `accelerate`).
- `remotion-composer/package-lock.json` remains lockfile v3 and is checked against both declared dependency maps in `package.json`.
