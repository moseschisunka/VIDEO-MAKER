# PR-900 — Immutable approval record

- Status: **VERIFIED**
- Scope: Define a self-digesting, append-only approval record bound to one project, run, attempt, stage, checkpoint version, and artifact digest.
- Implementation: `schemas/approvals/approval_record.schema.json`, `schemas/approvals/approval_log.schema.json`, and `lib/approval_contracts.py`.

## Evidence

- `build_approval_record` requires an explicit `approve`, `revise`, or `reject` decision and actor; it has no mutable `human_approved` authority.
- `record_digest` covers every immutable field. Tampering is rejected.
- `append_approval_record` uses atomic writes, file locking, duplicate-ID idempotency, and timestamp ordering.
- `validate_checkpoint_approval` binds the record to the exact checkpoint timestamp, artifact digest, stage, run, and canonical checkpoint reference.
