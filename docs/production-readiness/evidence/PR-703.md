# PR-703 — Runtime CDN removal and offline dependency contract

Status: **VERIFIED — offline runtime certified**

Production scaffolding no longer emits a public GSAP CDN. It writes
`vendor/gsap.min.js` from the repository-vendored GSAP 3.15.0 bundle and
records the dependency in `hyperframes.json`. Offline mode never calls `npm
view`; it recognizes the locally cached HyperFrames package and executes
`npx --offline` only.

Evidence:

```text
python -m pytest -q tests/contracts/test_phase7_gate.py
10 passed

HyperFrames 0.8.25 (offline cache), Node 22.13.1, FFmpeg 7.1, Chrome headless
offline strict sequence: lint (0 errors/0 warnings), validate (ok; 0 errors,
0 warnings, 0 contrast failures), inspect --strict (ok; 0 issues), render
--strict --workers 1 (90/90 frames; output validated).

Repository-vendored runtime: tools/video/vendor/gsap.min.js (72,927 bytes).
No `cdn.jsdelivr.net` reference exists in the generated production HTML.
```

`hyperframes doctor --json` reports optional missing integrations (whisper-cpp,
Kokoro TTS, MusicGen, and Docker); these are not required for the local
browser/FFmpeg render path and remain visible in the structured diagnostic.
The required Node/Chrome/FFmpeg/FFprobe checks pass. The old npm timeout is
retained as historical blocker evidence in the tracker and is superseded by
this local-cache certification.
