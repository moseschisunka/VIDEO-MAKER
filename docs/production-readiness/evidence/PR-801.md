# PR-801 — Music asset provenance

Status: **VERIFIED**

Music-library tracks, generated-provider results, and stock/music selector
results now expose a common `music_provenance` record. The record captures
source type/tool/provider, license and source links where available,
prompt/model for generated music, measured duration, loop permission, edit
rights, and an explicit `rights_status`. Unknown rights remain
`needs_review`/`unverified`; they are not promoted as licensed by inference.

The asset-manifest schema requires this record for every `type: "music"` row,
and mixed-media coverage validation reports incomplete music provenance.
