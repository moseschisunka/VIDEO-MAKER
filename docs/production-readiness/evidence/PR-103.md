## Implemented contract

Backlot now normalizes and validates all create-time selections before it
checks or creates `projects/<project-id>/`. The endpoint resolves the selected
pipeline through `lib.pipeline_loader.list_pipeline_catalog(...,
include_hidden=True)`, then enforces the reviewed release lane, manifest
validity, playbook compatibility, output profile/duration/aspect-ratio
contracts, declared source mode, runtime support, and provider/voice identifier
format. The provider boundary is structural only: no paid or network provider
call is made during validation.

Both legacy aliases (`tts_provider`/`profile`) and canonical request fields are
accepted only when they agree. Accepted normalized selections are persisted in
the proposal, project marker, and project configuration, including the voice
provider, renderer runtime, output profile, aspect ratio, and source mode. The
global release state remains explicitly non-production and locked to `PR-11G`.

## Rejection guarantees

The contract suite covers unknown, hidden/held, invalid and incompatible
playbooks, unsupported runtimes, undeclared source modes, unsupported profiles,
profile/aspect mismatches, malformed voice/provider identifiers, conflicting
aliases, and unsafe project IDs. Every rejection asserts that the temporary
projects directory is still empty.
