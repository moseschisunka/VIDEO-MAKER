# PR-207 — Actual media-property probing

Status: **VERIFIED**

## Implemented

- Added shared `probe_media`/`validate_media_contract` use across FFmpeg,
  Remotion, and HyperFrames render paths.
- Durable promotion already probes the candidate; direct non-durable render
  paths now probe the final output before returning success.
- Render reports can carry the actual codec, stream count, audio presence,
  format, SHA-256, and freshness data rather than inferred defaults.
- Manifest stage submission now ffprobes local render-report outputs and rejects
  declared resolution, fps, codec, audio codec, file-size, or duration values
  that disagree with the file on disk.
