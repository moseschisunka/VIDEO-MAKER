# PR-706 — Resource-safe worker policy

Status: **VERIFIED (policy contract)**

`select_worker_policy` treats video/animation or long high-resolution work as
resource-heavy and defaults it to one worker. Caller requests are capped at
the detected CPU count and cannot override the safe one-worker default for a
video-heavy composition without a separately measured policy change. The
render report records the requested and effective values.
