## Finding

Artifact media paths are stored relative to a project workspace, while Backlot
normally invokes the composer from the repository process.  The FFmpeg compose
path already resolved `edit_decisions.subtitles.source` against the project
root for caption burn-in.  The subsequent final-review subtitle check instead
called `Path(source).exists()` from the process working directory.  A valid
captioned source-footage render could therefore be marked `revise` even though
the subtitle file had been used successfully.

## Remediation

`VideoCompose._run_final_review` now accepts an optional canonical
`project_root`.  All high-level render paths pass the discovered project root,
and the subtitle check resolves the declared source through the same guarded
project-path resolver used by composition before checking file existence.  The
parameter is appended after the existing positional arguments to preserve the
caller's prior API order.  If no project root is known, legacy cwd-relative
calls remain supported.
