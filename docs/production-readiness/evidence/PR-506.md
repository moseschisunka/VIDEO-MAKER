# PR-506 — Transcript and pronunciation verification

Status: **VERIFIED**

`compare_transcript_to_script` and `verify_transcript` accept plain transcript
or word-timestamp/STT results, calculate sequence-aware word accuracy, detect
spoken punctuation leaks, report missing segment IDs, and preserve explicit
pronunciation notes. Missing or unreadable transcript data is an explicit
failure, not a silent pass.

Evidence: `tests/contracts/test_phase5_voice.py::test_transcript_verifier_catches_punctuation_leak_and_accepts_clean_text` and `::test_verify_transcript_accepts_word_timestamps_and_flags_missing_segments`.
