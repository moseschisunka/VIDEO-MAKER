# PR-807 — Accessibility and platform caption profiles

Status: **VERIFIED**

Media profiles now carry caption policy facts (maximum lines/characters,
minimum font size, reading speed, and bottom safe-area ratio). The shared
caption contract evaluates those policies plus WCAG-style foreground/background
contrast and records the measured accessibility report. Caption sidecars are
packaged inside HyperFrames workspaces, while burn-in runtimes apply the same
pixel safe-area margin.

Evidence:

```text
python -m pytest -q tests/contracts/test_phase8_caption_render.py
14 passed in 2.08s

python -m pytest -q tests/contracts/test_phase8_audio.py
7 passed in 1.86s
npm exec -- tsc --noEmit  (cwd: remotion-composer)
exit 0
```

The tests cover low contrast, undersized profile text, excessive reading speed,
line wrapping, portrait safe area, sidecar packaging, and the small-frame
Remotion safe-area regression.
