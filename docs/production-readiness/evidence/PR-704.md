# PR-704 — Strict lint/validate/inspect/render order

Status: **VERIFIED (adapter contract)**

`hyperframes_compose` exposes an explicit `inspect` operation. Production
renders run scaffold → strict lint → validate → strict inspect → render; any
failed gate returns a failed `ToolResult` and never invokes the renderer.
Non-production smoke scaffolds remain available for local adapter tests.

```text
python -m pytest -q tests/contracts/test_phase7_gate.py

```

The production-render contract test records the actual command order as
