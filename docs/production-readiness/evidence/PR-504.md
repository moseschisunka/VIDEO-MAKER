# PR-504 — Per-segment cache and resume

Status: **VERIFIED**

`VoiceSegmentCache` writes completed segment metadata atomically, verifies the
artifact exists and still matches its recorded SHA-256, and keys entries by the
deterministic segment ID. `execute_narration_segments` reuses valid completed
segments and stops at the first failed segment so a retry reruns only that
segment.

Evidence: `tests/contracts/test_phase5_voice.py::test_segment_cache_resumes_completed_work_and_reruns_only_failed_segment` and the Phase 5 failure matrix.
