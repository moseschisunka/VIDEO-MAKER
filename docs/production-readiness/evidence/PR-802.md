# PR-802 — Separate audio stems

Status: **VERIFIED**

`AudioMixer.full_mix` now supports an explicit `preserve_stems` production
path. It renders each narration, music, and SFX input to a normalized,
timeline-addressable WAV stem before building the single controlled final mix.
The result reports each stem id, role, source path, scheduled start, volume,
and output path; all stem files are included in tool artifacts. Legacy callers
can opt out explicitly and receive `stems_preserved: false`.
