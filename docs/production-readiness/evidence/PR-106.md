## Implemented contract

`lib.pipeline_loader.validate_manifest_agent_contract()` now produces a
read-only, structured compatibility report for each manifest. It validates the
manifest schema, resolves every stage director skill from the repository skill
tree, checks every produced and required-in artifact against a canonical
artifact schema, normalizes the permitted/required/preferred/fallback tool
policy, and requires explicit checkpoint, human-approval, review-focus, and
success-criteria declarations. It also reports effective release lane,
maturity, creation permission, required capabilities, and the mandatory
non-production gate.

`assert_manifest_agent_contract()` provides a strict error boundary for future
execution services. The canonical pipeline catalog embeds the same report and
exposes `agent_contract_valid` plus structured issues to Backlot/agents. Launch
candidates currently have complete contracts; held beta/experimental lanes
remain visible but are honestly `blocked` until their explicit runtime/profile
support metadata is completed. The hidden `framework-smoke` fixture is
reported as not user-facing and lacks director skills by design.

The validator performs no provider discovery call, credential access, asset
generation, or renderer execution.
