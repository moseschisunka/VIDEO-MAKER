# PR-502 — Voice-sample approval gate

Status: **VERIFIED**

`require_voice_sample_approval` blocks batch narration whenever a selection
declares `sample_approval_required` (or an equivalent required flag) without an
explicit approved sample record. Sample generation remains allowed, and the
TTS selector enforces the gate before provider selection or execution.

Evidence: `tests/contracts/test_phase5_voice.py::test_sample_gate_blocks_batch_until_explicit_approval` and `tests/contracts/test_phase5_gate.py::test_phase5_gate_rejects_unapproved_batch_without_provider_call`.
