# PR-305 — Approval-aware fallback

Status: **VERIFIED**

`lib/providers/fallback.py` classifies alternatives as equivalent,
material-provider, material-media, or unavailable. The executor blocks
material substitutions until `approved=True` and blocks an unavailable class;
the fallback plan exposes the alternatives and approval requirement before any
provider call.
