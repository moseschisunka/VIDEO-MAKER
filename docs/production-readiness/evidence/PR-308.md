# PR-308 — Cost reservation and reconciliation

Status: **VERIFIED**

`CostTracker` now accepts a provider idempotency key and metadata, reuses an
existing estimate on replay, makes reserve/reconcile/refund operations
idempotent, rejects terminal-state rewrites, and validates non-negative costs.
`ProviderExecutor` passes the key and provenance metadata to the tracker and
reconciles exactly once per attempt.
