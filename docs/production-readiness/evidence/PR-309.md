# PR-309 — Capability-family provider migration

Status: **VERIFIED**

`lib/providers/bridge.py` adapts existing provider implementations without
moving provider-specific payload logic. TTS, image, and video selectors now
always invoke the bridge; the new music selector does the same for the music
family. `MusicGen` also supports the explicit kernel marker for direct,
identity-bearing use, and `BaseTool` automatically routes direct
identity-bearing provider calls through the bridge. Production calls require a
complete run identity and explicit approval for paid execution.
