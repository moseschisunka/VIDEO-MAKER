# PR-1032 — Reject malformed motion cost guidance

Status: `IMPLEMENTED` locally; supported CI verification remains required.

## Finding

Cost estimation read `replication_guidance.motion_required` through Python
truthiness. Malformed guidance could therefore change the estimated motion
ratio and make a render plan appear cheaper or more expensive than its stated
media requirements.

## Remediation

- Accept only a real boolean when motion guidance is present.
- Treat an omitted field as the documented `false` default.
- Fail the cost calculation closed instead of silently changing the estimate.

## Local verification

The focused cost/Phase 0 contract set passes **42 tests**. No provider,
network, or paid-generation call was used; supported CI remains required.

## Residual scope and rollback

This hardens the cost boundary only. It does not certify provider pricing,
deployment limits, or `PR-11G`. Revert only with the finding and tests
preserved.
