# PR-505 — Safe audio assembly

Status: **VERIFIED**

`lib/audio_assembly.py` validates every input, creates an atomic concat
manifest, asks FFmpeg to decode/normalize/re-encode the ordered segments, and
verifies the resulting artifact is non-empty. The quarantined internal runner
now uses this utility instead of concatenating independently encoded MP3 bytes
with `-c copy`.

Evidence: `tests/contracts/test_phase5_audio_assembly.py::test_assembly_decodes_and_reencodes_ordered_segments`.
