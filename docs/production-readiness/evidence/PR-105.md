## Implemented contract

`lib/project_pipeline.py` is now explicitly documented and guarded as an
internal teaching/demo runner. It requires both an explicit `--internal-demo`
execution flag and a project marker containing `runner_kind: internal_demo`,
`demo_runner: true`, and the allow-listed demo pipeline identity. Visual-only
refreshes use the same guard.

Backlot `/api/project/{project_id}/run` no longer launches this runner for
ordinary projects. It returns HTTP 409 until a manifest-faithful agent executor
is registered. The only permitted API branch is the explicitly marked internal
fixture and its command includes `--internal-demo`. The generated per-project
`run_production.py` is now a quarantine stub and cannot import the legacy
runner. Variants are subject to the same explicit fixture boundary and carry the
marker forward for controlled visual testing.
