# PR-1009 — Bounded load and soak tests

Status: **VERIFIED (offline bounded-load gate)**

PR-1009 closes the Phase 10 local/fake scalability measurements without
contacting a network provider or creating paid work. The harness is deliberately
bounded to four workers, small UUID-scoped project fixtures, a finite SSE queue,
and a ten-iteration disposable temporary directory.

## Implemented safeguards

- `lib/load_harness.py` provides reusable JSON-producing probes for concurrent
  run isolation, same-project lease contention, fake-provider rate spacing,
  temporary-file cleanup, and SSE connect/disconnect stability.
- `scripts/measure_load_soak.py` is the operator/CI entry point; `make load-soak`
  is the corresponding Make target. It removes its own scratch root after the
  evidence is written.
- `ChangeHub` exposes a subscriber gauge, counts dropped notifications, and
  retains its 64-item per-subscriber queue bound. SSE handlers coalesce bursts.
- Remotion no longer passes a fixed `--concurrency=8`. It uses the conservative
  resource policy shared with HyperFrames, caps heavy/high-resolution work, and
  accepts only a bounded operator request.
