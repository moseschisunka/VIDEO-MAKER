# PR-1030 — Enforce strict HyperFrames policy and offline boundaries

Status: `IMPLEMENTED` locally; supported CI verification remains required.

## Finding

`HyperFramesCompose` used truthiness for `strict`, `production_mode`, and
`offline` across public and direct operation paths. Malformed values could
silently weaken production checks or change whether the runtime contacted npm.
Several direct operations could resolve a workspace or invoke the HyperFrames
CLI before policy validation, and unknown operations were not rejected at the
API boundary.

## Remediation

- Add one strict policy parser for `strict`, `production_mode`, and `offline`.
  Production mode is the union of the explicit production and strict flags.
- Validate policy controls before runtime probes, workspace creation/resolution,
  or CLI execution for execute, doctor, scaffold, lint, validate, inspect, and
  render paths.
- Preserve the instance-level offline override only when the request omits the
  `offline` key; an explicitly supplied value is always strict-parsed.
- Reject unknown or missing operations before any runtime probe.
- Carry the normalized offline state into render evidence and retain strict
  caption/render contract behavior.
