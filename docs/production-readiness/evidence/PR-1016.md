# PR-1016 — Approved source-footage talking-head executor

Status: `IMPLEMENTED` (local task gates pass; supported CI verification pending)

## Goal

Reconcile the approved Option A launch scope (`screen-demo` plus
source-footage `talking-head`) with the ordinary manifest-agent executor.  The
talking-head lane must prove a complete manifest-derived handoff and a
deterministic local render before it is admitted to the executor allow-list.
This task does not certify avatar/lip-sync generation, live providers, or
production readiness; the hard production gate remains `PR-11G`.

## Baseline

- Repository: `main`
- Baseline checkpoint: `0f9d0cf` (docs checkpoint after the verified
  project-relative caption fix)
- Dirty-file inventory before the task: clean
- Provider/network policy: no provider calls; local FFmpeg fixture only

The new release-blocking regression was run with:

```powershell
python -m pytest tests\contracts\test_phase10_talking_head_executor.py -q
```

Baseline result before the implementation change: **2 failed**.

1. `test_talking_head_manifest_faithful_golden_path` failed because
   `CERTIFIED_EXECUTOR_PIPELINES` contained only `screen-demo`.
2. `test_talking_head_run_returns_manifest_agent_handoff` received HTTP `409`
   with `Manifest-faithful executor for pipeline 'talking-head' is not
   certified yet.` despite the pipeline being creation-enabled by the
   canonical catalog and approved launch scope.

This is a reproducible contract mismatch, not an environment or provider
failure.

## Implementation

- Added `talking-head` to the explicit manifest-executor certification
  allow-list only after the golden test was written and the baseline failure
  was captured.
- Added a source-mode certification guard shared by Backlot and other
  executor callers: a persisted talking-head order with `source_mode` other
  than `source_footage` (or with no source mode) remains a deterministic `409`
  blocker instead of broadening the approved lane to avatar/lip-sync work.
- Added `tests/contracts/test_phase10_talking_head_executor.py`, which builds
  a real `talking-head` work order, submits schema-valid artifacts through all
  seven manifest stages, exercises the declared human approval gates, renders
  the source footage with FFmpeg and project-relative captions, validates the
  current output with ffprobe/final review, and completes publish.
- Added a Backlot contract proving an approved source-footage talking-head
  project receives the `manifest_agent` handoff and never spawns the legacy
  runner.
- Updated the playbook, tracker, and acceptance matrix to distinguish this
  local executor certification from the still-pending human AV, live-provider,
  operational, and `PR-11G` release gates.
