# PR-304 — Rate limits and circuit breaker

Status: **VERIFIED**

The executor spaces calls per provider using a deterministic limiter and opens
a provider circuit after the configured consecutive-failure threshold. An open
circuit returns a structured blocker and recovers only after its cooldown;
success resets the failure state.
