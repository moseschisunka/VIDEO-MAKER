# PR-1034 — Enforce schema boolean types at the shared tool boundary

Status: `IMPLEMENTED` locally; supported CI verification remains required.

## Finding

Provider tools declared boolean input properties but individual implementations
could still receive strings or integers and coerce them with `bool()`. This
created a repeated policy weakness across image, video, voice, and music tools.

## Remediation

- The instrumented `BaseTool.execute` wrapper rejects malformed top-level
  schema booleans before events, provider discovery, filesystem mutation, or
  network work.
- Keep tool-specific validation for nested objects and structured review
  reports; the character reviewer explicitly retains its report contract.

## Local verification

The shared-boundary plus media, HyperFrames, selector, and TTS focused set
passes **74 tests**. No credentials, network calls, or paid generation were
used; supported CI remains required.

## Residual scope and rollback

Nested contract fields and derived display booleans remain owned by their
specific validators. This does not certify live providers or `PR-11G`. Revert
only with the boundary regressions retained.
