# PR-402 — Hardcoded subject filler quarantine

Status: **VERIFIED**

The quarantined internal runner no longer fabricates generic “step N” slides
or generic narration for an unrelated topic. Non-domain work must provide an
explicit `template_beats` and `script_sections` payload; otherwise the runner
raises `ContentTemplateRequiredError`. Epidemiology defaults remain restricted
to the explicitly recognised internal dogfood subject, and custom templates
cannot accidentally trigger those defaults.

Evidence: `tests/contracts/test_phase4_grounding.py` and
`tests/contracts/test_phase1_demo_runner_quarantine.py`.
