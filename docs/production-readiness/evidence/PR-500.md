# PR-500 — Normalize voice identity model

Status: **VERIFIED**

`lib/voice_contracts.py` defines the immutable voice tuple: canonical provider,
model/variant, voice ID, locale, settings, and a SHA-256 identity key. Provider
aliases are canonicalized as identity aliases only; they never trigger a
fallback provider. The TTS selector rejects a preferred/allowed provider that
conflicts with the locked identity.

Evidence: `tests/contracts/test_phase5_voice.py::test_voice_identity_is_canonical_and_provider_alias_does_not_fallback`.
