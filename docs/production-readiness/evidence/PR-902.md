python -m pytest -q tests/contracts/test_phase9_approval.py tests/contracts/test_phase1_claim_resume.py

Result: pass. Approve resumes the manifest-derived next stage (or queues it when no worker is live); revise reopens the exact stage and records a blocker; reject cancels the order.
