# PR-805 — Caption rendering certification per runtime

Status: **VERIFIED**

All three composition runtimes now consume the same `lib.caption_contracts`
render contract. The contract validates cue ordering, positive timing, video
duration bounds, safe-area ratios/pixels, maximum characters per line, maximum
lines, font size, and a stable cue digest. It also records the transcript
verification report when captions originate from an approved transcript.

Runtime behavior:

- Remotion receives `captionContract` in the props and positions the caption
  box using contract pixel safe areas. The direct caption burner fixes the
  `staticFile()` path shape, preserves the approved digest, and uses the same
  contract for its FFmpeg fallback.
- HyperFrames renders certified segment/phrase overlays with deterministic
  GSAP visibility keyframes, or packages a certified JSON/SRT sidecar. The
  workspace retains `caption_render_contract.json` and the sidecar under
  `captions/`.
- FFmpeg validates SRT/VTT/SubtitleGen JSON before burn-in, materializes inline
  cues safely, applies the contract bottom margin, and reports the contract in
  the result. Sidecar mode skips burn-in while retaining the source path.

The sampled Remotion and HyperFrames frames were visually checked. Captions
are visible, readable, and inside the contract safe area; the 320x240 test
also caught and fixed the prior fixed-80px rule that placed captions at the
top of small outputs.

Boundary retained by design: HyperFrames is certified for segment/phrase
captions, not Remotion's word-level karaoke highlight. Briefs requiring that
effect remain locked to Remotion.
