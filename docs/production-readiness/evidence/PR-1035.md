# PR-1035 — Preserve structured character review reports

Status: `IMPLEMENTED` locally; supported CI verification remains required.

## Finding

The new shared schema guard pre-empted the character reviewer, whose contract
intentionally returns a structured successful `character_qa_report` with
`status: revise` so Backlot can present actionable issues. Treating that
report as a generic tool failure broke the review surface.

## Remediation

- Opt the structured reviewer out of the generic top-level boolean guard.
- Keep its own strict parser authoritative and preserve the structured report
  for malformed review inputs.

## Local verification

The character reviewer regression and shared guard checks pass **35 tests**.
The final local release/offline matrix is recorded after PR-1036; supported CI
must rerun it on the published checkpoint.

## Residual scope and rollback

This is a compatibility exception with explicit ownership, not a relaxation of
provider controls. It does not certify human audiovisual review or `PR-11G`.
Revert only with the structured-report regression retained.
