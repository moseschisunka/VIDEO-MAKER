# PR-301 — Deterministic ProviderExecutor

Status: **VERIFIED**

`lib/providers/executor.py` is the single bounded execution boundary. It does
not select providers, author prompts, change media types, choose fallbacks, or
advance stages. It validates requests/results, records structured events,
enforces approval/circuit/rate policy, bounds provider calls, and reconciles
outcomes.

Evidence:

```text
python -m pytest -q tests/contracts/test_phase3_provider_executor.py
8 passed
```

Timeouts return without waiting for an uncooperative provider; failures are
structured rather than leaked as provider exceptions.
