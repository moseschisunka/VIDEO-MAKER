# PR-404 — Canonical timeline and duration solver

Status: **VERIFIED**

`lib/video_timeline.py` now provides `solve_duration_plan` and
`validate_timeline_contract`. The solver works backward from target duration,
voice rate, word count, scene count, intro/outro, silence, and transitions;
returns explicit visual-hold budget; and rejects overlong narration instead of
speeding it up or hiding it with padding. `lib/media_profiles.py` owns the
canonical short/long tolerance policy.

Evidence: `tests/contracts/test_phase4_timing.py` and
`tests/contracts/test_phase4_gate.py`.
