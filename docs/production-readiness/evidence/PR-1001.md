# PR-1001 — Non-Python package data

- Status: **IMPLEMENTED — supported CI verification pending**
- Gate date: 2026-09-02
- Gate owner: OpenMontage execution agent
- Scope: Installed availability of pipeline manifests, Layer 2 skills, styles, schemas, templates, creator profiles, Backlot UI, configuration, ComfyUI workflows, vendored GSAP, and the Remotion composer project.

## Implementation

- Added explicit package markers for the data-bearing top-level directories (`config`, `content_templates`, `pipeline_defs`, `profiles`, `skills`, and `styles`).
- Added `setuptools` package-data rules for JSON/YAML schemas, Markdown/YAML skills, playbooks, templates, creator profiles, Backlot UI assets, ComfyUI workflow JSON, and vendored render assets.
- Added wheel data-file mappings for the legacy root-level `config.yaml`, the
  tracked `remotion-composer/` source/configuration tree, and three curated
  `public/demo-props` fixtures. This preserves the existing runtime path
  contract while the resource-root migration remains a separate hardening
  concern.
- Kept generated `node_modules`, project outputs, downloaded stock, per-run
  props, credentials, and user footage out of the package. In particular,
  `remotion-composer/public/talking-head/in.mp4` is runtime input, not a
  release asset; an earlier local-only expectation of that ignored file was a
  false-positive packaging contract and has been removed.
