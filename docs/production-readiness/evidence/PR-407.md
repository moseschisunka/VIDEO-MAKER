# PR-407 — Format and timing regression suite

Status: **VERIFIED**

The canonical tolerance is ±max(5%, 1s) for products up to 60 seconds and
±3% for long-form products. Regression tests cover 15s, 30s, 60s, and 300s
plans, measured drift, scene allocation, transitions, profile limits, and
short-form overrun behavior. Existing golden scenario tolerances were aligned
to the same policy.

Evidence: `tests/contracts/test_phase4_timing.py` and
`tests/contracts/test_phase4_gate.py`.
