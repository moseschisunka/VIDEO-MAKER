# PR-1024 — Fail closed on visual-review and transcript controls

Status: `IMPLEMENTED` locally; supported CI verification remains required.

## Finding

Several user-controlled review and caption policy fields were converted with
Python truthiness. Values such as `"false"`, `1`, or `0` could therefore change
the declared gate state: a character final review could appear checked, a
transcript verification flag could be accepted without a boolean contract, or
HyperFrames could silently enable/disable motion, looping, ducking, or the
contrast audit.

## Remediation

- Reject non-boolean character browser/frame review flags and unknown review
  levels; invalid values produce a `revise` QA report.
- Reject malformed `require_verified_transcript` and `transcript_verified`
  controls in SubtitleGen, Remotion caption burn, FFmpeg composition, and
  HyperFrames caption contracts before caption artifacts are created.
- Reject malformed HyperFrames `motion_required`, music `loop`, and ducking
  controls before mapping or sidecar generation.
- Reject malformed HyperFrames `skip_contrast` values before invoking the
  validation CLI, preventing a string false from becoming a quality-check
  opt-out.
- Add regression coverage for string, integer, null, and collection values;
  valid boolean final-review inputs remain accepted.
