## 3. Trusted-edge security & rate-limiting (`SEC-06`)

The web perimeter boundary was certified per `config/security_policy.yaml`:

- **CORS Policy:** Strict same-origin policy; cross-origin wildcards (`*`) or unlisted origins receive HTTP 403.
- **CSRF Posture:** Stateless Bearer token authentication required on all mutating endpoints (`/api/projects`, `/api/runs`, `/api/approvals`). Cookie-based session authentication is strictly rejected.
- **Edge Rate Limiting:** Perimeter reverse proxy configured to enforce HTTP 429 throttling:
  - General API: 100 requests/minute per client IP.
  - Run Creation: 10 requests/minute per client IP.
  - Ingestion / Media Upload: 20 requests/minute per client IP.

**Result:** **PASS (`SEC-06`)**.
