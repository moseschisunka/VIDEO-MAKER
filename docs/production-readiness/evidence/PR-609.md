# PR-609 — Asset cache and partial resume

Status: **VERIFIED**

`AssetCache` keys entries by canonical request hash, copies atomically, stores
validation/provenance metadata, verifies current size and SHA-256 on reuse, and
removes corrupt entries so only the affected asset is regenerated. Image/video
selectors expose the cache as an optional run-local optimization.

Evidence: Phase 6 cache resume and corruption-regeneration test passes.
