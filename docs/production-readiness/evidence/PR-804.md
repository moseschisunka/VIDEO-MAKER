# PR-804 — Captions from a verified transcript

Status: **VERIFIED**

`validate_verified_transcript` now requires explicit approval/verification,
language, non-empty words or segments, positive monotonic timestamps, and
optional comparison against the approved narration text. It emits a stable
transcript digest. `SubtitleGen` accepts the canonical transcript and, when
`require_verified_transcript: true`, fails closed before writing captions if
the transcript is unverified, wrong-language, overlapping, or text-drifting.
Generated caption results retain the verification report and digest.
