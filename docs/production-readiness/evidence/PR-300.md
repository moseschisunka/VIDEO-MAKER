# PR-300 — Provider request/result contracts

Status: **VERIFIED**

Implemented `lib/providers/contracts.py` and versioned JSON schemas under
`schemas/providers/`. Requests carry capability, operation, provider/model,
payload, stable idempotency, optional project/pipeline/run/attempt/stage
identity, timeout/retry policy, cost estimate, approval, fallback class, and
metadata. Results carry status, attempt/latency, estimated/reserved/actual/
refunded cost, artifacts with hash/size/probe fields, structured errors, and
provenance.

Evidence:

```text
python -m pytest -q tests/contracts/test_phase3_provider_contracts.py
3 passed
python -m py_compile lib/providers/contracts.py
```

The test validates both request/result JSON schemas and fail-closed identity,
policy, and structured-error validation.
