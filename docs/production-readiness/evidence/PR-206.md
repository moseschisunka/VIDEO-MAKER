# PR-206 — Cancellation, restart, and resume

Status: **VERIFIED**

## Implemented

- Added durable `cancel_work_order` and `restart_work_order` transitions.
- Cancellation is terminal for the current attempt but preserves all
  checkpoints, artifacts, and the manifest-derived resume stage.
- Restart reopens only the first non-completed stage, clears the terminal
  timestamp, and records operator/reason/restart-count metadata.
- Expired leases can be reclaimed through the existing resume endpoint; the
  work order and run record record the recovered worker and recovery reason.
- Added Backlot `/cancel` and `/restart` endpoints; lifecycle events are
  appended to the project event stream.
- Run-record synchronization now merges lifecycle metadata and clears stale
  `finished_at` when a cancelled run is explicitly reopened.
