# PR-401 — Deterministic grounding validator

Status: **VERIFIED**

`lib/grounding.py` performs no network calls. It resolves stable source IDs,
URLs, titles, and legacy data-point references; classifies factual versus
creative/opinion/instruction text; preserves supported, contradicted,
uncertain, unsupported, and missing-source states; and returns a serialisable
report. Unsupported or uncertain high-risk claims produce `block`; other
non-supported factual claims produce `revise`.

Evidence: `tests/contracts/test_phase4_grounding.py` and
`tests/eval/test_phase4_grounding_eval.py` pass supported, contradicted,
uncertain, missing-source, creative, and opinion cases.
