# PR-803 — Measured audio quality enforcement

Status: **VERIFIED**

Output profiles now carry explicit integrated-LUFS targets/tolerances, true
peak limits, silence limits, and clipping limits. `audio_quality_probe` measures
the rendered samples with FFmpeg `ebur128`, `volumedetect`, and
`silencedetect`, returning a serializable report with loudness, true peak,
maximum sample level, clipping samples, silence intervals, and actionable
errors. `AudioMixer.full_mix` can enforce the report with `quality_check: true`
and uses profile loudness/true-peak targets in its normalization filter.
Ducking values are validated and bounded; invalid levels fail closed.
