# PR-702 — Fades, stems, and ducking

Status: **VERIFIED (adapter contract)**

HyperFrames workspaces now emit separate direct-child narration, music, and
SFX audio elements. Music carries volume, loop, fade-in, fade-out, and
ducking parameters; the main paused timeline emits deterministic volume
keyframes for fades and narration overlap ducking. No raw audio-byte
concatenation or silent stem collapse is performed by this adapter.

certification held by `PR-703`/`PR-709`.
