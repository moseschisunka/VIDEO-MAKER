# PR-1033 — Validate selector audiovisual controls

Status: `IMPLEMENTED` locally; supported CI verification remains required.

## Finding

Image, video, and music selectors did not consistently validate operation and
quality controls before discovery or ranking. Truthy strings/integers could
change motion, batch, watermark, instrumental, or production behavior.

## Remediation

- Validate selector operations and target fields before provider discovery or
  ranking.
- Enforce strict booleans for the audiovisual controls and preserve normalized
  values for downstream providers.
- Keep unknown operations fail-closed.

## Local verification

The selector-focused/adjacent contract suite passes **261 tests**. No live
provider or network work was used; supported CI rerun remains required.

## Residual scope and rollback

This closes selector dispatch/control coercion. It does not certify provider
quality, live media, or the Phase 11 human audiovisual gate. Revert only with
the associated tests and evidence retained.
