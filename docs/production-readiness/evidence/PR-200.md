## Baseline reproduction

The existing Remotion diagnostics regression suite reproduced the Phase 0
failure before the fix:

```text
python -m pytest -q tests/tools/test_remotion_diagnostics.py
4 failed, 1 passed
NameError: name 'edit_decisions' is not defined
  tools/video/video_compose.py:2045
```

`_remotion_render()` accepted either `edit_decisions` or
`composition_data`, but its long-form timeout calculation unconditionally
read the undefined local `edit_decisions`. That caused even error-reporting and
timeout tests to crash before the Remotion subprocess could run, hiding the
actual renderer diagnostic.

## Implementation

The timeout calculation now derives planned duration from the already validated
`composition_data` payload. This keeps both direct `composition_data` calls and
the normal high-level `edit_decisions` path on the same code path, while
preserving the existing timeout pass-through, stderr-tail reporting, and
cleanup behavior. No fallback runtime was introduced.
