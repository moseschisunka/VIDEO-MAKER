# PR-503 — Deterministic narration segmentation

Status: **VERIFIED**

`plan_narration_segments` normalizes text and derives stable segment IDs from
section identity, normalized text/hash, the complete voice identity, and the
pronunciation dictionary version. Every segment carries ordered start/end
timing, expected/measured duration fields, and the voice identity key.

Evidence: `tests/contracts/test_phase5_voice.py::test_narration_segment_ids_and_timeline_are_stable`.
