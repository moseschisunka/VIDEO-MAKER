# PR-800 — Proposal-stage music decision

Status: **VERIFIED**

The proposal contract now requires an explicit music decision. Supported
choices are `user_library`, `ai_generated`, `bring_your_own`, and `none`.
`none` requires a reason and cannot carry a track path; the other choices have
source details appropriate to their type. The internal pipeline persists the
normalized choice before proposal validation and appends an auditable
`music_source` decision with all four options to `decision_log.json`.

Evidence:

```text
python -m pytest -q tests/contracts/test_phase8_music.py tests/contracts/test_phase0_contracts.py tests/contracts/test_taste_governance_contracts.py tests/qa/test_08_end_to_end.py
43 passed in 135.16s
```

The shared proposal skill and explainer, animation, character-animation, and
cinematic proposal-director instructions now point to the same contract. No
music asset may be generated or inferred before this decision is recorded.
